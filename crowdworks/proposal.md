# 提案文テンプレート（クラウドワークス／A分野: GAS・業務自動化）

300〜500字。【】は案件ごとに埋める。**埋めずに出さない。**
型の根拠と禁止フレーズは Vault `30_Outputs/2026-09/RESEARCH-ai-sidebiz-crowdsourcing.md` §5。

## 共通の9要素（この順に並べる）

1. 宛名＋1行挨拶
2. **募集文の課題・固有名詞を冒頭で復唱**（最も効く。ここを外すとテンプレ扱いされる）
3. どう解くか1行
4. 案件に近い実績だけ＋URL
5. 募集文の質問に全部答える（抜けなし）
6. 見積もり内訳・納期・修正回数・稼働・返信速度を数字で
7. 想定リスク1つと回避策を先回り
8. 確認質問は1〜2問だけ
9. 返信しやすい締め

## 出す前のチェック

### 禁止フレーズ（入っていたら書き直す）

- 「初心者ですが」「未経験ですが」「勉強中です」 — 発注側の発信で落選理由として名指しされている
- 「頑張ります」「精一杯」「誠心誠意」 — 中身が無い
- 「他より安く」「格安で」 — 安い案件しか来なくなる
- 募集文の指示（「〇〇と添えてください」等）の無視 — 一発で落ちる

### 応募前の4条件（1つでも欠けたら応募しない）

1. 認定クライアント、または本人確認済み
2. 報酬額が明示されている（「ワーカーと相談する」は避ける）
3. 応募数が30人未満
4. 下の禁止文言が無い

### 募集文にあったら応募しない文言（クラウドワークスの禁止事項そのもの）

- 無報酬でのテストライティングやサンプル作成
- 仮払い前の作業が必要
- 契約前の連絡先交換・面談・説明会への参加が必要
- メッセージで具体的に答えず外部連絡先へ誘導
- 初回だけサービスを使い、その後は直接取引
- スキルアップ・実績・成長を対価にした低単価
- 個人情報の収集が目的
