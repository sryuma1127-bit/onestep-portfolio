# 使用スキル

## 技術

- Google Apps Script（Web アプリ・トリガー・Drive / Calendar 連携）
- Google Sheets（データ設計・数式の無害化・直接編集の検知）
- HTML / CSS / JavaScript（スマホ向けの単一ページ UI）
- Git / GitHub（ブランチ運用・CI でのテスト）
- clasp（Apps Script への反映）
- Claude Code（要件整理・設計・実装・テスト・自己レビュー）

## 業務

- 業務設計（要件定義・業務フローの棚卸し・現場の運用を変えない設計）
- 業務自動化（転記・集計・締切管理・帳票への自動記入）
- テスト設計（画面とサーバーの計算の同形を固定・境界値・再送の収束）
- 運用設計（権限・個人情報の分離・変更履歴・バックアップと復旧）
